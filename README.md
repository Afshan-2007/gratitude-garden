# 🌱 Gratitude Garden

A visual gratitude journal where each daily memory grows into a plant over time.

I wanted a simple way to remember at least one positive thing from every day — even if it was something small like a comfort movie, a long drive, good food, or a peaceful moment.  
So I built a project that turns those memories into a growing garden.

---

## ✨ Features

- One gratitude entry per day
- Streak tracking
- Plants grow over time 🌱🌿🌸
- Animated clouds and wind effects
- Persistent storage using browser localStorage
- Responsive and calming UI

---

## 🛠 Tech Stack

- React
- TypeScript
- CSS

---

## 🌿 Concept

Each gratitude entry plants a seed.  
As days pass, the seed grows into a sprout, then a sapling, and eventually blooms into a flower — creating a visual garden of memories and consistency.
